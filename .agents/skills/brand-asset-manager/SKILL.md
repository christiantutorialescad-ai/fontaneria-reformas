# Skill: Brand Asset Manager

Guía para la creación y estandarización visual de la marca **FONTANERÍA REFORMAS (F&R)**.

## Identidad Visual y Elementos Gráficos

1. **Logotipo Circular (Badge Isotipo)**:
   - Texto circular superior: `FONTANERÍA`
   - Texto circular inferior: `CONSTRUCCIÓN`
   - Núcleo central: Silueta arquitectónica (tejado con chimenea), llave inglesa cruzada, muro de ladrillo con llana/paleta y las siglas destacadas `F&R`.
   - Borde con aro doble o estrellas indicando "20 AÑOS DE EXPERIENCIA".

2. **Paleta de Colores Corporativa**:
   - Azul Primario (Confianza & Seguridad): `#1B3B6F` / `#162E56`
   - Azul Océano / Fontanería: `#0284C7` / `#0ea5e9`
   - Naranja Construcción / Fuego: `#EA580C` / `#F97316`
   - Verde WhatsApp / Confirmación: `#22C55E` / `#25D366`
   - Fondo Claro: `#F8FAFC`
   - Texto Oscuro: `#0F172A`
   - Blanco Puro: `#FFFFFF`

3. **Formatos y Optimización de Imágenes**:
   - Logotipo principal en formato SVG vectorial escalable y nítido para cualquier resolución retina/4K.
   - Fotografías para los servicios con compresión adecuada, `aspect-ratio` definido para evitar Layout Shifts (CLS), y carga diferida (`loading="lazy"`).
